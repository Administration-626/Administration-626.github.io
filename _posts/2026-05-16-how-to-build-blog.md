利用 GitHub Pages 搭建个人博客是一个非常不错的选择，免费且易于管理。本文将介绍基本的搭建步骤。

首先，你需要一个 GitHub 账号，并创建一个名为 `username.github.io` 的仓库。

接着，你可以选择自己写 HTML，或者使用 Jekyll 这样的静态网站生成器。Jekyll 的好处是可以让你使用 Markdown 格式来编写文章，然后自动生成网页。

我们现在就在使用 Jekyll！
